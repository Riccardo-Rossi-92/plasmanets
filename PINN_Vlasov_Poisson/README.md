# PINN-Vlasov-Poisson

Code accompanying the paper:

"Phase-Space Reconstruction from Macroscopic Observables via 
Integration-Free Physics-Informed Neural Networks for the 
Vlasov–Poisson System"

R. Rossi, P. Gaudio, M. Gelfusa, A. Murari

*Nature Computational Science* (submitted)

## Structure
- 01_forward_two_stream/   → Forward model, two-stream instability
- 02_forward_landau/       → Forward model, Landau damping (perturbative)
- 03_inverse_two_stream/      → Inverse problem, phase-space reconstruction
